Privacy: what this site records

This site has no forms, no accounts and no ads, and it sets no cookies. Visits are counted with GoatCounter, a privacy-friendly counter, and the pages are hosted on GitHub Pages. Nothing you type into the deadline calculator leaves your browser.

What GoatCounter counts

According to the GoatCounter privacy policy (checked 24 October 2026):

  • It stores counts of the page path, the referrer, the browser and operating system name and version, the country (worked out from the IP address), the language and the screen size.
  • It does not store IP addresses, the full browser User-Agent or any tracking ID, and it stores nothing in your browser: no cookies and no localStorage.
  • To tell a new visit from a repeat one, it keeps a record of the site, IP address and User-Agent in memory for up to 8 hours.
  • It says it does not share this information with third parties.

You can block the counter with any content blocker. The site works the same without it.

What the host records

The site is served by GitHub Pages. GitHub's documentation says that when a GitHub Pages site is visited, the visitor's IP address is logged and stored for security purposes (What is GitHub Pages?, checked 24 October 2026). See the GitHub General Privacy Statement for more.

What we never ask for

We never ask for your complaint details, policy or account numbers, passwords, OTPs, card numbers, KYC documents or money. The deadline calculator runs only in your browser. Official sites linked from our guides have their own privacy policies.
